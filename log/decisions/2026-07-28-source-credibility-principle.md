# 决策 · 文献 credibility 的相对量化原则（研究者，2026-07-28）

**原文要旨（研究者口述）：** 对这样一个主观 topic，我们可能无法说一个文献会 100% 准确。只能**相对**量化文献的 credibility，然后试图理解文献**分析的具体视角来源**。

## 操作化（本项目如何执行）

1. **不设绝对真值。** 文献评估回答的不是「这本书对不对」，而是两个可回答的问题：
   - **传承可信度（相对）**：文本以何种谱系留存至今——版本可查程度、托名/层积程度、异本分歧程度。只作相对分级（如：清晰 / 层积 / 存疑），且可随核验修订。
   - **视角来源**：这份文献从哪个位置发言——哪个流派、哪个时代、原文还是注释层、回答的是（若三问假说成立）哪一问。理解视角不是消解内容，而是给内容定位。
2. **与既有架构的关系：** 此原则落在 provenance schema 的 `reliability` 自由文本字段与四轴中的 **可考** 轴上，是对其用法的细化，不修改 schema 本身（schema 为 Tier-2）。
3. **推论：** 文献间的**分歧本身是数据**（视角差异的证据），不是需要裁决掉的噪音。收敛式多源印证仍按 §4 记录为 可考 证据。
