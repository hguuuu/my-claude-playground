# Study Plan Overview

*Last updated: 2026-07-27 · Status: Phase 1 in progress (entered with a headstart — see §2)*

## 1. Goals

Two simultaneous goals across five systems (Tarot, Lenormand, Western astrology, 八字, 易经):

1. **Practical reading competence** — able to read fluently, eventually for clients (staged: self → friends → paid, with ethics code).
2. **Scholarly understanding** (the "outside view") — history, sociology, psychology, philosophy, symbolism; always distinguishing **documented history** from **interpretive tradition**.

**Core method:** for each system, pair one *inside-view* book (practitioner/primary source) with one *outside-view* book (scholarship). The tension between them is where real understanding happens.

## 6. Why this ordering (dependency logic)

- **RWS alone first (~6 months):** it's the mentorship subject (feedback loop) and the most legible system; a second tarot variant too early creates interference before the first is stable.
- **Marseille waits (P3):** confusable variants must be *blocked* until each is stable, then deliberately contrasted. Marseille's pip method (image, no fixed meanings) is structurally incompatible with RWS keyword reading — that's why it must wait, and why it's valuable.
- **Astrology waits until P4 but unlocks everything after:** decan mastery makes Thoth, Le Tarot Astrologique, and the deeper Golden Dawn correspondences *meaningful* rather than memorized. It also carries the biggest time cost (Brennan: 100+ lecture hours), so it must not compete with the tarot-fluency push.
- **千里命稿 → 子平真诠 → 滴天髓:** the canonical Chinese difficulty ladder — vernacular bridge → coherent 格局 system → terse advanced capstone. Out of order = drowning.
- **Lenormand after RWS courts:** its literal fixed-keyword grammar is the *opposite* of tarot intuition; add it once tarot intuition can be consciously switched off.
- **Etteilla last:** idiosyncratic system best approached with Dummett history internalized + French reading + stable RWS (note: Waite lifted keywords *from* Etteilla — genealogically upstream, pedagogically last).

**Bridges between tracks:** decans = astrology↔tarot; correlative cosmology (Granet) = 八字↔易经; comparative structural tables = East↔West.

```
RWS majors → RWS 78 + Dummett thesis → { Marseille, Lenormand }
千里命稿 → 子平真诠 → 滴天髓 → (advanced classics)
Astrology (Brennan) → decans → { Thoth, Tarot Astrologique, deep GD correspondences }
Etteilla ← needs { Dummett + French + stable RWS }
```

## 7. Assessment: how each phase is completed

Completion = **passing exit criteria, not calendar time.** Four assessment instruments:

1. **Blind production tests.** Shuffle, draw 3 cards on a real question, read aloud (record it) with no books. Pass = coherent and specific twice, two weeks apart. (八字 equivalent: hand-cast a chart from the 万年历, full 十神 assignment.)
2. **Mentor as examiner.** Show the mentor the phase's exit criteria and ask directly: "am I there yet?" The 1-on-1 mentor is the best assessment instrument available; same for the 八字 teacher checking 十神/用神 work.
3. **Journal verification stats.** After 6–8 weeks of logged predictions there is an actual hit/miss record — evidence of whether readings are informative or generically Barnum-flavored.
4. **Teach-back test (scholarly track).** Explain the phase's key thesis out loud in two minutes without notes (e.g., the Dummett thesis; where the 五行/four-elements analogy breaks). Can't do it = reading not finished.

Because of the headstart, test against Phase 1 criteria **now** — any already passed shifts emphasis immediately rather than waiting out the calendar.

## 8. Risk management & adaptation rules

- **Contamination rule (tarot):** Marseille/RWS meanings bleeding together → revert to RWS-only 2–4 weeks, re-separate.
- **Bleed rule (astrology/八字):** concepts merging (地支 ≠ zodiac signs; no 神煞 in Western charts) → pause astrology, re-block. The comparative table is the *reward* for separation, not a shortcut to fusion.
- **Client gate:** no paid readings until Stage 2 delivery practice + written ethics code; Hyman/Barnum reading is prerequisite to reading for anyone.
- **Certification** (ISAR CAP / NCGR-PAA; ATA/TCBA ethics): only if professional ambitions crystallize.
- **If life intervenes, cut in this order:** (keep always) daily draw + journal → (keep) live lessons → (protect) prediction verification → (cut first) French track + optional books → (cut second) knowledge-base elaboration. Never start a new system before the current one is stable — pausing is fine; contaminating is not.
- **Trust the schedule over felt fluency:** spacing/interleaving *feel* less effective than cramming while producing better retention (Bjork's desirable difficulties).

## 9. Mentorship synchronization (biweekly cadence)

1. Pre-read upcoming cards 1–2 days before each session.
2. Arrive with a written list of specific stuck-readings and questions accumulated since last session.
3. Within 24h after: free-recall brain dump of the session before consulting notes, then reconcile.
4. Spaced review of session content at ~day 2, 7, and 14 (right before the next session).

Use the between-session ask-the-teacher channel for single stuck cards; save structural questions for sessions.
