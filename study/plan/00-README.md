# Divination Study Plan — Document Index

Personal study guides for a five-system divination program: **Tarot (RWS → Marseille → Etteilla/Tarot Astrologique) · Lenormand · Western astrology · 八字 · 易经**.

## How to use these documents

- **Start of each phase:** open the phase file. It tells you prerequisites, goals, why each book was chosen, what you're reading/practicing/testing for, and how to know you're done.
- **These are living documents.** Only the current and next phases are commitments; later phases are placeholders to be re-planned at each boundary based on what actually happened. Update files as you learn — the plan serves the study, not the reverse.
- **Store in your knowledge repo** under `plan/` (see file 07 for the repo architecture).
