# INDEX — /study/inbox

> Map-of-content. Keep current: this is how sessions orient without reading everything (PROJECT_BRIEF §2).

**Purpose:** Landing zone for raw study-plan uploads. Drop files here as-is — any format, any language, no frontmatter, no naming convention required.

Nothing here is canonical, citable, or trusted. It is unprocessed input.

## How this gets processed

A later session (`intake:` for material about a tradition, `engineering:` for course-driven formal-layer work) reads what arrived, then:

1. Files study material into `/study/` under whatever structure the actual content warrants.
2. Routes anything out-of-scope to `/seeds/` (§1.5) rather than letting it expand the current workstream.
3. Opens `/queue/` tasks for real research work the material implies — one task per unit, small granularity (§8). It does **not** do that research in the intake session.
4. Records in `/sources/` only what is a genuine verified primary text (§1.2). A course PDF is not one.

Processed items are removed from `inbox/` so that whatever remains here is always "not yet looked at".
