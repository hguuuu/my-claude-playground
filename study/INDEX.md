# INDEX — /study

> Map-of-content. Keep current: this is how sessions orient without reading everything (PROJECT_BRIEF §2).

**Purpose:** The researcher's own **parallel study plan** — courses, curricula, study summaries, exercise sets, progress tracking. This is the *learning* track running alongside the *research* corpus.

This directory is an addition to the §2 layout, created at the researcher's request (session 0002). It exists because study material is a real, ongoing input to this project (the brief already anticipates it: §7 names "the researcher's own training need … tied to her chart calculation course", and `/queue/` carries `slice1-train-001/002`), but it is **not** the same kind of object as the research corpus and must not be filed as if it were.

## The boundary — read before filing anything here

| | `/study/` | research corpus (`/sources/`, `/schools/`, `/lexicon/`, …) |
|---|---|---|
| What | course notes, curricula, study plans, drills, personal summaries | verified primary texts and notes derived from them |
| Citable? | **No.** Never cite a study note as evidence for a claim about a tradition. | Yes, under §1.2 |
| Provenance | light — see below | full schema (brief §3) required |

Three rules that do not bend:

1. **`/study/` is not `/sources/`.** A course handout is not a verified primary text. If a course quotes 渊海子平, that quote is `verification: unverified` until a copy of the source itself lands in `/sources/` and an `audit:` session checks it. Course materials are a *pointer to* sources, never a substitute for one.
2. **Language policy still applies (§1.1).** 八字 study notes in Chinese, astrology study notes in English. Study material is not a translation zone. If a course itself teaches across languages, that observation belongs in `/comparative`, quoted natively on each side.
3. **Study content earns its way into the corpus, it does not leak into it.** When something learned here becomes a research claim, it goes through the normal path — an `intake:` session against a verified source, a lexicon entry, or a rule spec. The study note stays here; the corpus note is written fresh from the source.

## Layout

- `inbox/` — raw uploads land here unprocessed. No provenance requirement, no structure imposed. A later session reads what actually arrived and decides how to file it.

Further structure (by tradition, by course, by term) is deliberately **not** pre-built: it will be shaped by the files, not guessed at before them.

## Tier

Tier 1 for leaf content — study notes, summaries, drill sets, progress entries auto-commit.
Tier 2 for this INDEX and for any change to the boundary rules above (they touch the citation constitution).
