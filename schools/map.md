# 八字流派与方法族 · Phase-0 地图 v0

> **性质：** Phase-0 输出，**允许出错**，随 depth-work 修正（brief §6）。
> **护栏：** 以下凭通识整理，一手文献尚未入 /sources/，故所有典籍归属、时代、分派一律 `verification: unverified`（§1.2）。仅列一行取向与关系，**不作深入 profile**（那是 phase0-004 与 depth-work 的事）。
> **提醒：** 流派分类是研究**输出**，不是立项假设。此图的修订史本身即研究记录。

## 首要分野：古法 / 今法（本位之别）

- **古法（年本位）** — 以年柱为命主，多用纳音论命；徐子平之前的主流取向。关系：为今法前身，干支/五行材料共享，本位不同。
- **今法（日本位·子平）** — 以日干为「我」，用十神与格局论命；后世主流。关系：涵盖下列 B/C/D 多数分支。

## 方法族 A · 古法 / 纳音

- **纳音法（李虚中一路）** — 年柱纳音为纲，重年、胎、月。关系：与子平共享干支材料，分歧在本位（年 vs 日）与取象（纳音 vs 十神）。

## 方法族 B · 子平 · 格局本位

- **传统子平 / 格局派** — 以月令定格，论成格败格、相神救应而取用神。关系：与旺衰派同宗子平，分歧在「取用神之路」（论格局 vs 论强弱）。

## 方法族 C · 用神 · 旺衰 / 调候本位

- **旺衰扶抑派（近代新派一路）** — 以日主强弱定扶抑用神。关系：子平内部取用神分歧之一极，与格局派既对立又互补。
- **调候派（穷通一路）** — 以月令寒暖燥湿定调候用神。关系：多作格局/旺衰之补充，未必全然独立。

## 方法族 D · 象法 / 口诀 · 断验本位

- **盲派（盲师断法）** — 重象法口诀、体用宾主，长于断事验事，弱于格局理论。关系：技法自成传承一系，与理论派取向不同，干支材料仍共享。

## 跨层 · 神煞

- **神煞用法** — 贵人 / 桃花 / 驿马 / 空亡等神煞判断，可附着于上述任一派。关系：**非独立流派**，是一层可叠加的判断材料，各派轻重不一。

## 近现代 · 融合 / 心理化

- **港台及现代融合** — 兼采诸法，或引入心理学等外部框架。关系：融合层，边界待 depth-work 厘清。
